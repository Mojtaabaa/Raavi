# sandbox-defaults — shipped with the version

The default settings of this version (`config/*.json`). **Replaced on every upgrade; do not edit.** Your own values live in `../sandbox/config`. `Raavi.Migrator sandbox sync` copies settings that are new in this version into your files; scalar defaults also act as the lowest configuration layer at run time. See `sandbox/README.md`.

`collaboration.env.example` — template for `sandbox/secrets/collaboration.env`, read by the collaboration server.
