# Labels (Tags) — User Guide

## Assigning labels

On a page you can edit, use the labels row under the content: type to autocomplete, or accept a suggestion. Click a label to open its results page.

## Browsing

`/labels/{slug}` shows description, parent/children, related labels (from pages you can see), and matching pages. Use **Match any / Match all** and **Include child labels** — these update the URL for sharing.

## Administration

Workspace administrators: **Administration → Labels**. Create/edit (name, colour, parent, aliases), archive/restore, merge with preview, delete unused, and view usage analytics.

## Search

Smart search accepts an optional comma-separated label filter with any/all mode and descendant inclusion. Results stay permission-filtered.

## Notes

- Confluence-style short names (no spaces) still work for assign/import/workflows.
- Renaming the display name does not change the URL slug.
- Archived labels stay on historical pages but cannot be newly assigned until restored.
