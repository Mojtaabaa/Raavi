# Implementation Roadmap

Each phase follows the per-phase procedure (requirements → scope → DB → API → frontend → backend → frontend → tests → build/test → fix → docs → status). A phase is complete only when its acceptance criterion is demonstrated by executed tests.

## Cross-phase rules
- The tenant isolation suite grows every phase and runs on every CI build.
- Each phase updates `docs/IMPLEMENTATION_STATUS.md` and `FEATURE_MATRIX.md`.
- Open questions Q1–Q5 (`REPOSITORY_ASSESSMENT.md` §6) are resolved before the phase they block.
